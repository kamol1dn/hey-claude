# Service icons

Monochrome logos from [Simple Icons](https://simpleicons.org) 13.21.0, released
under CC0 1.0. Each file is the upstream single-path SVG with `fill="#F2F2F2"`
added so it reads on the island's black pill. They are shown only to name the
service a tool is using ("Google Calendar · list events"); brands keep their own
trademarks.

Left out on purpose: `anthropic` and `claude`. Nothing on the island copies or
evokes the Claude or Anthropic mark (docs/island-motion.md, section 1).

To add one: put `<slug>.svg` from the same release here (same edit), and map
the MCP server to the slug in `ui/services.json`.
